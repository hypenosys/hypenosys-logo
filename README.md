# Hypenosys — identidad visual v2

Identidad pixel art 8-bit inspirada en Commodore/PETSCII. Paleta: violeta `#6C5CFF`, lima `#A8F020`, blanco y fondo oscuro.

- `logo_simple.svg`: logotipo completo (wordmark).
- `logo_icon.svg`: símbolo para aplicaciones y redes.
- `favicon.svg` y `favicon.ico`: iconos de navegador.
- `favicon-16x16.png`, `favicon-32x32.png`, `android-chrome-*.png` y `apple-touch-icon.png`: variantes para dispositivos.
- `previews/`: miniaturas de la identidad.
- `source/`: SVG originales y paquete comprimido de procedencia.
- `scripts/generate_brand.py`: generación reproducible y validación de las imágenes.

No modificar los binarios a mano: regenerar desde las fuentes SVG.
